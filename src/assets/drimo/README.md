# Assets oficiais Drimo

Os arquivos locais desta pasta vieram da curadoria oficial do Drive da Drimo.
O manifesto em `src/config/assets.ts` separa pratos, drinks, ambiente e Chef
Diego para reduzir a repetição visual entre as seções.

As fotografias JPG originais foram mantidas em alta resolução. A conversão
para WebP/AVIF pode ser feita no pipeline de publicação, sem substituir os
originais usados como fonte.

Nenhuma imagem externa ou gerada por IA é usada como fallback.
